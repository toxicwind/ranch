# smoke-two-sum

Write a python module `solution.py` defining:

```python
def two_sum(nums: list[int], target: int) -> list[int]:
```

Return the indices `[i, j]` (i != j) such that `nums[i] + nums[j] == target`.
Exactly one valid pair is guaranteed to exist. Order of the two indices does
not matter.

Constraints: any correct implementation passes; this is a harness smoke test,
not a benchmark.
