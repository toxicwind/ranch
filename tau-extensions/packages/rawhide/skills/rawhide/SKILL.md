# Rawhide — Unvarnished Prose Engine

Rawhide is a technical prose linter designed for engineers and AI coding agents.

## Principles

1. **Unvarnished Declarative Truth**: Cut throat-clearing, marketing fluff, and AI stylistic tells ("delve", "tapestry", "seamless", "game changer", "testament").
2. **Natural Technical Syntax**: Semicolons, em-dashes, contractions, and Latin abbreviations ("e.g.", "i.e.") are first-class English tools, not defects.
3. **Markdown-Aware**: Never penalize bullet points, tables, code blocks, or headings as runaway sentences.
4. **Epistemic Calibration**: Express uncertainty with explicit Kesselman confidence scales ("certain", "highly likely", "likely", "possible", "unlikely", "remote").

## Usage

```bash
bun test packages/rawhide/tests/
```
